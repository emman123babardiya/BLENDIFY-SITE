# Blendify — Sip Your Mood

Front-end website for Blendify, a café-style juice bar brand (AI mood-based drink recommendations, exotic fruit blends), built for a university Innovation & Entrepreneurship project.

## Files
- `index.html` — page structure
- `style.css` — all styling (colours, layout, responsive rules, light/dark theme)
- `script.js` — mood picker + menu tab interactivity

## Run it
No build step, no dependencies. Just open `index.html` in any browser, or double-click the file.

To host it for free:
1. Push this folder to a GitHub repo.
2. Go to **Settings → Pages**, set source to the `main` branch, root folder.
3. GitHub gives you a live link like `https://<username>.github.io/<repo>/`.
